# 🎮 משחק דמקה - שחור נגד כתום

משחק דמקה קלאסי לשני שחקנים על אותו מחשב, בצבעי שחור וכתום.
בנוי ב-HTML, CSS ו-JavaScript טהורים - בלי תלויות, פשוט פותחים בדפדפן ומשחקים.

## ✨ תכונות

- 🔐 מסך כניסה לשני שחקנים עם שם משתמש וסיסמא
- ♟️ לוח 8x8 קלאסי עם 12 כלים לכל שחקן
- 👑 הכתרה אוטומטית למלכה בשורה האחרונה
- 🎯 אכילה חובה - הכלי שחייב לאכול מהבהב
- 🔄 רב-קפיצה (multi-jump) - אכילה רצופה עם אותו כלי
- 🏆 זיהוי אוטומטי של ניצחון
- 📱 רספונסיבי - עובד במחשב, טאבלט וטלפון

## 🎲 חוקי המשחק

1. **שחור מתחיל** - השחקן בצבע שחור משחק ראשון
2. **תנועה אלכסונית** - כלי רגיל זז משבצת אחת אלכסונית קדימה
3. **אכילה** - קופצים מעל כלי של היריב אל משבצת ריקה אלכסונית. הכלי הנאכל יורד מהלוח
4. **אכילה חובה** - אם יש אפשרות לאכול, חובה לקחת אותה
5. **רב-קפיצה** - אם אחרי אכילה אפשר לאכול עוד, חייבים להמשיך עם אותו כלי
6. **הכתרה למלכה** - כלי שמגיע לשורה האחרונה הופך למלכה (♛) ויכול לזוז ולאכול בכל ארבעת הכיוונים
7. **ניצחון** - מנצחים אם ליריב לא נשארו כלים או שאין לו מהלך חוקי

## 🚀 איך להפעיל

פשוט נכנסים לקישור של הדף.

### מקומית
1. הורידו את הקבצים
2. פתחו את `index.html` בדפדפן

זהו! אין מה להתקין.
